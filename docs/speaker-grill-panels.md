# Speaker grill panels

Open **Add Speaker Grill** on the main toolbar, between Import Backglass Image and Backglass Brightness.

Choose a built-in panel with **Choose template**, or use **Import image** for your own artwork. Set the height in pixels and inspect the preview before applying. The panel matches the backglass width and is appended beneath the original image; existing artwork and object positions remain unchanged. Existing backglasses that already have a grill boundary are protected from this add-on operation.

The grill boundary is set automatically. The Server uses its existing grill show/hide option for the added section. Add lights, text, LEDs, and score reels to the new area using the normal tools. Template display openings are artwork; DMD routing is not reassigned.

**Save to My Templates** saves the imported image as a named PNG. **My Saved Templates** opens a picture-and-name grid of images in `My Templates\Speaker Grills` beside the installed B2SPro.exe. You can add PNG, JPEG, BMP, GIF, or TIFF images directly to that folder. Duplicate names receive a numbered suffix; existing templates are not overwritten. Your saved templates are local user files and are not bundled into release downloads.

An applied panel can be edited, replaced, removed, or undone. Shrinking or removing it is blocked if doing so would cut off lights or score objects in the panel area. Save the project and use Step 1 – Create B2SPro File to update the file used by VPX.

For the separate DMD canvas, import a DMD background image before adding objects. Current Image switches the Layers list between Backglass and DMD.
